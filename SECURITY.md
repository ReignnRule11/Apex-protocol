# Security Policy

APEX is pre-alpha research software. Do not use it to custody funds, secure production assets or operate a validator with economic value.

Report sensitive vulnerabilities privately through GitHub Security Advisories where enabled; otherwise contact maintainers through a private channel. Do not post secrets, private keys, seed phrases or personal data in issues.

In-scope risks include consensus safety/liveness, deterministic execution, replay protection, canonical encoding, P2P parsing, state integrity, RPC authorization, validator key handling, checkpoint verification and supply accounting. Passing tests are not a security audit; there is no production network or security guarantee.
